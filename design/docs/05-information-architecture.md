# 05 Information architecture

## โครงเดียวทุกหน้า

```
[● ● ●]  หน้าหลัก  ขาย  ประวัติขาย  กะและลิ้นชัก  สินค้า  รายงาน  ตั้งค่า        [ค้นหาหรือสั่งงาน  Ctrl K]  ร้าน · เครื่อง
[toolbar ของหน้านี้ · จัดกลุ่ม · ขอบเขตชัด ........................................ มุมมอง (segmented)]
[ pane ] [ pane ] [ details pane ]
[พนักงาน | ออฟไลน์ · รอ sync | กะ · เปิด | ลิ้นชัก | เครื่องพิมพ์ ........ สีหลัก | เสียง | รูปทรง | ภาษา | density | เวลา]
```

| Workspace | แผงหลัก | สถานะ |
|---|---|---|
| **หน้าหลัก** `Alt 1` | สถานะกะ + ปุ่มขายต่อ/ปิดกะ · ยอดวันนี้ · ต้องทำ · บิลพัก/โต๊ะที่เปิด | Current |
| **ขาย** `Alt 2` | ตะกร้า · หมวด · สินค้า · มุมมอง *โต๊ะ* (ผังโต๊ะตามโซน) | Current (โต๊ะ: Future) |
| **ประวัติขาย** `Alt 3` | รายการจัดกลุ่ม + ตัวกรอง · ใบเสร็จ + ลำดับเหตุการณ์ | Current |
| **กะและลิ้นชัก** `Alt 4` | ขั้นตอน · นับเงิน · ตรวจยอด | Current |
| **สินค้า** `Alt 5` | หมวด/มุมมอง/จัดการ (ชุดตัวเลือก, วัตถุดิบ, ผู้ขาย) · ตาราง · แผงแก้ไขแบบแท็บ | Current |
| **รายงาน** `Alt 6` | KPI · กราฟ · รายรับตามวิธีชำระ · สินค้าขายดี | Current |
| **ตั้งค่า** `Alt 7` | เมนูพร้อมคำอธิบาย + ค้นหา · การ์ด SettingsRow · SaveBar | Current |
| ลูกค้า / ครัว | — | Future — ครัวเป็นหน้าต่าง/อุปกรณ์แยก |

**กติกาการขยาย:** เพิ่ม workspace ได้เมื่อมีผู้ใช้ที่ใช้เป็นงานหลักและใส่เป็นมุมมองไม่ได้ · ฟีเจอร์ที่ร้านไม่เปิดใช้ต้องไม่ปรากฏ · ทุกหน้าค้นเจอจาก Ctrl K

## ตำแหน่งที่ห้ามย้าย

ตะกร้าซ้าย สินค้าขวา · ปุ่มยืนยันล่างสุดของแผง · สถานะกะ/การเชื่อมต่อใน status bar · ปิด overlay มุมขวาบน + `Esc`

## ตามอุปกรณ์

Desktop compact/touch: โครงเดียวกัน · Tablet: แท็บ workspace ย่อเป็นเมนู, ตะกร้าเป็นแถบล่าง · KDS: ไม่มีแท็บ, ตัวกรองสถานี · หน้าลูกค้า: ไม่มี chrome ใช้แบรนด์เต็มจอ — สองอย่างหลังยังต้องออกแบบในสไตล์ v0.2
