# 05 Information architecture

## หลัก: workspace ไม่กี่อัน + มุมมองภายใน + command bar

ระดับบนสุดมีแค่ **workspace** (งานใหญ่ที่คนสลับไปมาวันละหลายครั้ง) ฟีเจอร์ใหม่ส่วนใหญ่จะเข้าไปเป็น*มุมมอง*หรือ*แท็บ*ใน workspace ที่มีอยู่ ไม่ใช่เมนูใหม่ระดับบน
ทุกอย่างค้นหาและเปิดได้จาก **command bar** (`Ctrl K` หรือแตะช่องค้นหาในแถบบน) จึงไม่ต้องจำว่าเมนูอยู่ตรงไหน

```
แถบบน: [Workspace ▾]  สาขา · เครื่อง   [ค้นหาหรือสั่งงาน  Ctrl K]   (ออฟไลน์) (กะ #12 · สมชาย)
```

| Workspace | สถานะ | มุมมอง / แท็บภายใน |
|---|---|---|
| **หน้าหลัก** | Current | สถานะกะ · ยอดวันนี้ · ทางลัด · งานค้าง (ปิดกะต่อ, สำรองข้อมูล) |
| **ขาย** | Current | บิลปัจจุบัน · พักไว้ · ล่าสุด → *Future:* แท็บ โต๊ะ, ออเดอร์ออนไลน์ |
| **ประวัติขาย** | Current | รายการบิล · ใบเสร็จ · ยกเลิก/คืนเงิน |
| **กะและลิ้นชัก** | Current | เปิดกะ · เงินเข้า/ออก · ปิดกะ · ประวัติกะ |
| **สินค้า** | Current | ทั้งหมด · หมวดหมู่ · มุมมองที่บันทึกไว้ (สต็อกต่ำ, หมด, ปิดขาย) → *Future:* ตัวเลือก/modifier, ชุดสินค้า, ซื้อเข้า, ตรวจนับ |
| **รายงาน** | Current | ประจำวัน · สินค้าขายดี → *Future:* ช่วงเวลา, พนักงาน, export |
| **ตั้งค่า** | Current | ร้าน · ภาษา/ธีม/density · สำรองข้อมูล → *Future:* อุปกรณ์, ภาษี, พนักงานและสิทธิ์ |
| **ลูกค้า** | Future | สมาชิก · คะแนน · ประวัติ (เข้ามาเมื่อเปิดฟีเจอร์เท่านั้น) |
| **ครัว** | Future | ไม่ใช่ workspace บนเครื่องขาย — เป็นแอป/โหมดแยกบนจอครัว |

**กติกาการขยาย:** workspace ใหม่เพิ่มได้ก็ต่อเมื่อ (1) มีผู้ใช้กลุ่มชัดเจนที่ใช้มันเป็นงานหลัก และ (2) ใส่เป็นมุมมองของ workspace เดิมไม่ได้ · ฟีเจอร์ที่ร้านไม่ได้เปิดใช้**ต้องไม่ปรากฏ**ใน UI (ไม่ใช่แค่ปิดเป็นสีเทา)

## การสลับบริบท (Future: หลายเครื่อง/หลายสาขา)

breadcrumb `สาขาหลัก · เครื่อง 1` ในแถบบนเป็นตัวสลับบริบท · เมื่อกดจะเปิด Popover รายการสาขา/เครื่อง · **การเปลี่ยนสาขาระหว่างที่มีบิลค้างต้องถามก่อน** และห้ามเปลี่ยนได้ระหว่างกะเปิดอยู่บนเครื่องขาย

## Navigation ตามอุปกรณ์

| อุปกรณ์ | Navigation หลัก | เหตุผล |
|---|---|---|
| Desktop compact | Workspace switcher (เมนูพร้อมคีย์ลัด `Alt 1–7`) + command bar | ประหยัดพื้นที่ คนประจำใช้คีย์ลัด |
| Desktop touch | เหมือนกัน แต่เป้ากดใหญ่ขึ้น · ใช้ Rail แสดงตลอดก็ได้ถ้าจอ ≥ 1280 | คนใหม่เห็นตัวเลือกตลอด |
| Tablet | Workspace switcher + แถบหมวดหมู่ด้านบน · ตะกร้าเป็นแถบด้านล่าง | ใช้มือเดียว นิ้วโป้งถึงปุ่มชำระเงิน |
| Web back office | SideNav แบบเต็ม (workspace + มุมมอง) | งานจัดการ ข้อมูลเยอะ จอกว้าง |
| KDS | ไม่มี nav · ตัวกรองสถานี (ร้อน/เย็น/บาร์) | อ่านอย่างเดียว แตะเพื่อเปลี่ยนสถานะ |
| หน้าลูกค้า | หมวดเมนู + ตะกร้า | เน้นแบรนด์ ใช้ density touch และตัวอักษร × 1.125 |

## ตำแหน่งที่ต้องคงที่ (ห้ามย้ายระหว่างหน้า)

- ตะกร้า + ยอด + รับเงิน **อยู่ซ้าย** · สินค้าและค้นหา **อยู่ขวา** (desktop)
- ปุ่ม commit อยู่**ล่างสุดของพื้นที่งานนั้น** และ**ขวาสุด**ใน Dialog/ฟอร์ม
- สถานะกะและการเชื่อมต่ออยู่**มุมขวาบน**เสมอ
- ปุ่มปิด overlay อยู่**ขวาบน** และ `Esc` ใช้ได้เสมอ
