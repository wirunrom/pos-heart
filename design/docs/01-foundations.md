# 01 Foundations

ค่าทุกตัวในหน้านี้มี token กำกับ (ดู 02 Tokens) — ห้ามใส่ค่าสีหรือขนาดตรง ๆ ลงใน component

**ค่าอะไรเปลี่ยนตามอะไร**

| เปลี่ยนตาม | สิ่งที่เปลี่ยน | สิ่งที่คงที่ |
|---|---|---|
| **Theme** (Light / Dark / System) | สีเชิงความหมายทั้งหมด, เงา | ขนาด, ระยะ, รูปทรง, ตัวอักษร |
| **Density** (compact / touch) | ความสูง control, ระยะในแถว, ขนาด body/label/money, ขนาด icon, การแสดงคำใบ้คีย์ลัด | สี, radius ของพื้นผิว, type scale ของหัวข้อ |
| **Platform** (desktop / tablet / KDS / customer / web back office) | density เริ่มต้น, ตัวคูณขนาดตัวอักษร, theme เริ่มต้น (KDS = dark), layout | semantic tokens และ component anatomy |
| **Brand** | `brand.name`, logo, ramp ที่ใช้ทำ `accent-*` | ทุกอย่างที่เหลือ |

## สี

**โครงสร้าง:** neutral สีอุ่น (stone) ใช้กับพื้นผิวและข้อความทั้งหมด · **accent สีเดียว** (saffron) · ชุดสีสถานะ 4 สี (success เขียว, warning ส้ม, danger แดง, info น้ำเงิน) · สี focus แยกเป็นน้ำเงิน เพื่อไม่ให้ focus ไปปนกับ accent

| บทบาท | ใช้กับ | ห้ามใช้กับ |
|---|---|---|
| `accent-bg` | ปุ่ม commit **หนึ่งปุ่ม**ต่อมุมมอง: รับเงิน, บันทึก, ยืนยัน, พร้อมเสิร์ฟ | ปุ่มรอง, ตกแต่ง, สถานะ warning |
| `accent-soft` / `fg-accent` | nav ที่ active, หมายเหตุ/ตัวเลือกอาหาร (modifier), บรรทัดที่เลือก | ข้อความยาว |
| `bg-selected` + `border-selected` | สิ่งที่*ถูกเลือก* (บรรทัดในตะกร้า, การ์ดสินค้าที่อยู่ในตะกร้า, แถวในตาราง) | สิ่งที่แค่ hover |
| `success / warning / danger / info` | ความหมายเชิงสถานะเท่านั้น และมีข้อความกำกับเสมอ | สีหมวดหมู่สินค้า, ปุ่มหลัก |
| `danger-solid` | ปุ่มที่ทำลายข้อมูลและย้อนกลับไม่ได้ (ยกเลิกบิล) | ปุ่มลบที่ undo ได้ (ใช้ `danger-quiet`) |

**กติกาเรื่องการแยกแยะ:** สถานะที่ต้องดูออกว่าต่างกัน ต้องต่างกันที่*ข้อความ*ก่อน แล้วค่อยต่างที่ความสว่าง ไม่ใช่แค่สี (เช่น "เหลือ 3" ส้ม กับ "หมด" แดง)
เงินที่ติดลบใช้เครื่องหมาย `−` (U+2212) เสมอ และใช้ `danger-fg` เป็นตัวช่วยเสริม ไม่ใช่ตัวบอกหลัก

**ตรวจ contrast แล้ว (WCAG 2.2 AA) ทั้ง Light และ Dark:** ข้อความ ≥ 4.5:1 บน surface/sunken/selected · ขอบ control และ focus ring ≥ 3:1 · สีกราฟ ≥ 3:1 · `fg-subtle` ใช้ได้กับ placeholder/disabled เท่านั้น (ได้รับยกเว้นตามเกณฑ์)

## ตัวอักษร

| Family | Token | ใช้กับ | เหตุผล |
|---|---|---|---|
| **IBM Plex Sans Thai** + IBM Plex Sans | `font-ui` | ข้อความทั้งหมด | ตัวไทยแบบไม่มีหัว ทันสมัย มี 7 น้ำหนัก ออกแบบคู่กับตัวละติน Plex ทำให้ไทยและอังกฤษมีน้ำหนักและความสูงใกล้กัน ใช้สัญญาอนุญาต OFL |
| **IBM Plex Mono** | `font-num` | **จำนวนเงินทุกที่**, จำนวนชิ้น, รหัส, เวลานับถอยหลัง | ตัวเลขทุกตัวกว้างเท่ากันโดยไม่ต้องพึ่ง OpenType `tnum` (egui ไม่รองรับ) หลักหน่วย/สิบ/ร้อยจึงตรงกันทุกบรรทัด |

**Type scale** (compact → touch): display 30/40 · title-lg 22/32 · title 17/26 · body 14/22 → **16/26** · label 13/20 → **15/22** · caption 12/18 · money-xl 34/40 · money-lg 22/28 · money 14/22 → **16/24** · money-sm 12/18

- **ภาษาไทยต้องการ line-height มากกว่าอังกฤษ** (มีสระบน/ล่างและวรรณยุกต์) — ใช้ line-height ≥ 1.45 กับ body และห้ามมีข้อความเล็กกว่า 12px
- ห้ามบีบตัวอักษร (`letter-spacing` ติดลบ) กับข้อความไทย ใช้ได้เฉพาะตัวเลขขนาดใหญ่
- **ตัดคำไทย:** ห้ามตัดกลางพยางค์ ถ้า toolkit ไม่มี word break ภาษาไทย ให้ใช้ dictionary segmentation (ICU / `icu_segmenter` ใน Rust) หรือให้ตัดบรรทัดได้เฉพาะที่ช่องว่างกับ `+ / ( )`

## ระยะ, ขนาด, grid และการจัดแนว

- **Base 4px**, scale: 0 · 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 (`space-*`)
- **ความสูง control** compact / touch: sm 28/40 · md 36/48 · lg 44/56 · xl (ปุ่ม commit) 52/64 · แถว 40/56
- **Hit target:** โหมดสัมผัสต้องกดได้อย่างน้อย 44×44 เสมอ (ส่วนที่มองเห็นเล็กกว่าได้ แต่พื้นที่กดห้ามเล็กกว่า) ระยะห่างระหว่าง target อย่างน้อย 8px
- **Layout ของแอป:** แถบบน (52/64) + พื้นผิวที่ลอยบนพื้น canvas ห่างกัน 10px ไม่มี 12-column grid บนเดสก์ท็อป ใช้**คอลัมน์ตามหน้าที่**แทน (ตะกร้ากว้างคงที่ + สินค้ายืดตามจอ)
- **การจัดแนว:** ตัวเลขชิดขวา, ข้อความชิดซ้าย, หัวคอลัมน์ชิดตามข้อมูลในคอลัมน์นั้น, ป้ายกับค่าอยู่บน baseline เดียวกัน (`ds-kv`)

## รูปทรง, เส้นขอบ, ความสูงของชั้น (elevation)

| ชั้น | พื้น | radius | เงา | ตัวอย่าง |
|---|---|---|---|---|
| Canvas | `bg-canvas` | — | — | พื้นหลังแอป |
| Surface | `bg-surface` | lg 12 | shadow-1 | ตะกร้า, ตาราง, การ์ด |
| Raised | `bg-raised` | md 8 | — / shadow-2 | การ์ดสินค้า, เมนู, popover |
| Sunken | `bg-sunken` | md 8 | — | สรุปยอด, หลุมใส่ข้อมูล, ตัวที่ใช้ไม่ได้ |
| Overlay | `bg-raised` + scrim | xl 16 | shadow-3 | dialog, sheet |

control ใช้ radius sm 6 (compact) / md 8 (touch) · badge ใช้ xs 4 · pill ใช้ full
เส้นแบ่งในพื้นผิวเดียวกันใช้ `border-subtle` · ขอบของ input ใช้ `border-control` (≥ 3:1)
ลำดับชั้นซ้อน: base 0 → sticky 10 → dropdown 100 → sheet 200 → dialog 300 → toast 400

## Iconography

ใช้ icon แบบเส้น บน grid 24 · เส้นหนา 1.8 · ปลายมน · ขนาด 16 / 20 / 24 (`icon-*`)
icon **ประกอบ**ข้อความ ไม่ได้แทนข้อความ — ปุ่มที่มีแต่ icon ได้เฉพาะการกระทำรองที่เข้าใจกันทั่วไป (ปิด, เพิ่มเติม, พัก) และต้องมี `aria-label` กับ tooltip
แนะนำให้ใช้ [Lucide](https://lucide.dev) (ISC license) เป็นฐาน เพราะมีรูปทรงตรงกับสเปกนี้ และ export เป็น SVG ไป rasterize ใน egui ได้

## Motion

| Token | ค่า | ใช้กับ |
|---|---|---|
| `duration-instant` | 0ms | เลือก, focus, พิมพ์ — งานขายต้องตอบสนองทันที |
| `duration-fast` | 120ms | hover/press |
| `duration-base` | 200ms | popover, toast, ไฮไลต์บรรทัดที่เพิ่งเพิ่ม |
| `duration-slow` | 280ms | sheet/dialog (ตอนปิดใช้ 0.7×) |

easing แบบ standard `cubic-bezier(.2,0,0,1)` · **ห้ามมี motion ที่ทำให้ต้องรอก่อนจะกดต่อได้**
**Reduced motion** (ตั้งค่าใน OS หรือในแอป): duration ทุกตัวเป็น 0, skeleton หยุดกระพริบ, การเปลี่ยนตำแหน่งใช้ fade แทน

## Accessibility และวิธีป้อนข้อมูล

- **Focus:** ring สีน้ำเงิน 2px เว้นจากขอบ 2px มองเห็นได้ทั้งสองธีม และแสดงเฉพาะตอนใช้คีย์บอร์ด (`:focus-visible`)
- **ลำดับ focus บนหน้าขาย:** ช่องค้นหาได้ focus อยู่เสมอ (รองรับ barcode scanner) → `↑/↓` เลื่อนบรรทัดในตะกร้า → `+/−` แก้จำนวน → `F9` รับเงิน ดูรายการครบใน 04 Patterns
- **ป้อนได้ 3 แบบเท่ากัน:** คีย์บอร์ด (มีคีย์ลัดทุก action สำคัญ) · เมาส์ (มี hover state) · สัมผัส (ไม่มีอะไรที่ต้อง hover ถึงจะเห็น ไม่ใช้ long-press เป็นทางเดียว)
- **โปรแกรมอ่านหน้าจอ:** ใน egui ใช้ AccessKit (`eframe` เปิดได้) ทุก widget ต้องมี label · เมื่อยอดเปลี่ยนต้องประกาศแบบ polite
- **ขนาดข้อความ:** ผู้ใช้ปรับ UI scale ได้ 90–150% (egui `pixels_per_point`) โดย layout ต้องไม่พัง

## Density และการปรับตามอุปกรณ์

| | Compact | Touch |
|---|---|---|
| ค่าเริ่มต้นบน | เดสก์ท็อปที่ใช้เมาส์/คีย์บอร์ด, web back office | จอสัมผัส, tablet, KDS, หน้าลูกค้า |
| Control / แถว | 36 / 40 | 48 / 56 |
| คำใบ้คีย์ลัด | แสดง | ซ่อน (คีย์ลัดยังใช้ได้) |
| การ์ดสินค้า | กว้างขั้นต่ำ 136, สูง 84 | กว้างขั้นต่ำ 176, สูง 104 |
| ตะกร้า | แก้จำนวนด้วยคีย์ลัด/แตะ | แตะบรรทัดเพื่อเปิดตัวแก้ไข (stepper + ตัวเลือก + ลบ) |

ผู้ใช้สลับ density ได้ในแถบบนหรือในตั้งค่า แอปจำค่าไว้แยกตามเครื่อง และไม่ต้องรีสตาร์ท

## หน้าจอปรับขนาด (Responsive / resizable)

| ความกว้าง | หน้าขาย | หน้าจัดการ (สินค้า/รายงาน) |
|---|---|---|
| < 900 (tablet แนวตั้ง) | สินค้าเต็มจอ + ตะกร้าเป็นแถบล่างที่ขยายได้ (bottom sheet) | ตารางเป็นรายการ, ตัวกรองอยู่ใน sheet |
| 900–1199 (ขั้นต่ำ 1000×700) | ตะกร้า 360 + สินค้า, หมวดหมู่เป็นคอลัมน์ 148 | sidenav + ตาราง, ตัวแก้ไขเปิดเป็น sheet |
| ≥ 1200 (1280×820) | ตะกร้า 392 (touch 420) | sidenav + ตาราง + inspector 340 |

**ห้ามซ่อนเงินเมื่อพื้นที่ไม่พอ** — ให้ชื่อตัดบรรทัด, ซ่อนคอลัมน์ที่ไม่สำคัญ หรือเลื่อนแทน ส่วนยอดรวมและปุ่ม commit ต้องอยู่ในจอเสมอ (pinned)

## Localization

| เรื่อง | กติกา |
|---|---|
| ข้อความยาว | เผื่อภาษาอังกฤษยาวกว่าไทย ~30% และเยอรมัน/อื่น ๆ ~60% ปุ่มขยายตามข้อความได้ ไม่ตัด ellipsis ในปุ่ม |
| ชื่อข้อมูล (สินค้า, ลูกค้า) | ตัดบรรทัดได้สูงสุด 2–3 บรรทัด แล้วจึงตัด พร้อมแสดงชื่อเต็มเมื่อ focus/hover/แตะค้าง |
| เงิน | ใช้ locale token: สัญลักษณ์ `฿`, ทศนิยม 2 ตำแหน่ง, คั่นหลักพันด้วย `,`, เครื่องหมายลบ `−` · ห้ามย่อเป็น "1.3K" ในหน้าทำงาน (ใช้ในแกนกราฟได้เท่านั้น) |
| จำนวน/หน่วย | `3 ชิ้น`, `1.25 กก.` — ใช้ทศนิยมได้สูงสุด 3 ตำแหน่งสำหรับสินค้าชั่งน้ำหนัก หน่วยเป็นข้อมูลของสินค้า ไม่ใช่ข้อความคงที่ |
| วันที่ | ไทย: `13 ต.ค. 2569` (พ.ศ. เป็นค่าเริ่มต้น เปลี่ยนเป็น ค.ศ. ได้) · อังกฤษ: `13 Oct 2026` · ใน export/ข้อมูลใช้ ISO 8601 |
| เวลา | 24 ชั่วโมงทั้งสองภาษา `14:05` · ระยะเวลาเขียน `9 ชม. 41 นาที` / `9h 41m` |
| ตัวเลขไทย | ใช้เลขอารบิกเสมอ (๑๒๓ ไม่ใช้ใน UI) |
