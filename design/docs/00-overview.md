# POS Design System

ภาษาการออกแบบของผลิตภัณฑ์หน้าร้าน เริ่มจากแอปขายหน้าร้าน desktop ที่ทำงานแบบ offline (Rust · egui)
**v0.2 · Proposed** — ทิศทางผ่านการเลือกแล้ว รายละเอียดพร้อมนำไปทำ แต่ยังไม่ได้ทดสอบกับผู้ใช้จริง

> "POS Heart" เป็นชื่อชั่วคราว ชื่อ โลโก้ และสีแบรนด์อยู่ใน `brand.*` ชั้นเดียว · tokens และ components ตั้งชื่อตามหน้าที่ เปลี่ยนแบรนด์ได้โดยไม่ต้องแก้ component

## ทิศทาง v0.2: "โปรแกรมทำงานจริง ที่ทันสมัย"

- **ธีมเดียว** — กรอบโปรแกรมสีกราไฟต์ (title bar, toolbar, status bar) + พื้นที่ทำงานสีกระดาษ ภาพรวมเป็นกลาง ไม่สว่างหรือมืดเกินไป ส่วนที่ต้องอ่านยังชัดเต็มที่ · เลิกใช้ Light/Dark
- **ฟีลโปรแกรม desktop** — แท็บ workspace อยู่ในแถบชื่อโปรแกรม · toolbar ตามหน้า · แผงรายละเอียดด้านขวา · status bar ที่กดได้ · ข้อมูลแน่น ตัวอักษร 13px
- **รูปทรงโค้ง (modern)** — แผงลอยบนกรอบ เว้น 6px โค้ง 10px · ปุ่ม/ช่องกรอก 8px · ไฮไลต์แบบโค้งเว้นขอบ (มีโหมดเหลี่ยมสำรอง)
- **สองโหมดความหนาแน่น** — เมาส์/คีย์บอร์ด (compact) และจอสัมผัส (touch) ใช้ layout เดียวกัน ต่างกันแค่ขนาด · touch: เป้ากด ≥ 44px ซ่อนคำใบ้คีย์ลัด หมวดสินค้าเป็นแถวปุ่ม
- **สีหลักสีเดียว** (ค่าเริ่มต้น หญ้าฝรั่น) ใช้กับการกระทำที่ทำให้เงินเคลื่อนเท่านั้น · มีชุดสีสำรอง 4 ชุดสำหรับเปลี่ยนแบรนด์

ดูของจริงได้ที่การ์ด **AppConcept** (กลุ่ม Reference screens) — กดใช้ได้ทุกหน้า

## หลักการ (เรียงตามลำดับเมื่อขัดกัน)

1. **เงินต้องถูกและอ่านครบ** — ทุกหลักรวมทศนิยม ตัวเลขกว้างเท่ากัน ชิดขวา · ยอดขาย / รายรับ / เงินในลิ้นชัก / สถานะชำระ แยกคำแยก component
2. **ขั้นต่อไปชัดเสมอ** — ปุ่มสีหลักหนึ่งปุ่มต่อมุมมอง · ปุ่มที่กดไม่ได้เป็นสีเทาและ **บอกเหตุผล** ("ใส่จำนวนเงินที่รับ")
3. **ขอบเขตชัด** — การกระทำของ *รายการ* อยู่ใต้บรรทัด · การกระทำของ *ทั้งบิล* อยู่ใน toolbar กลุ่ม "ทั้งบิล"
4. **ยืนยันทุกการกระทำ** — เพิ่มของแล้วบรรทัดกะพริบ ตัวเลขเด้ง มีเสียง · ผิดพลาดมีเสียงต่ำ + ข้อความบอกวิธีแก้
5. **แก้ได้ก่อนถาม** — undo ก่อน confirm · ถามยืนยันเฉพาะสิ่งที่ย้อนไม่ได้ พร้อมผลเป็นตัวเลข
6. **Offline คือปกติ** — ขายต่อได้เสมอ สถานะ sync อยู่ใน status bar ไม่ขัดจังหวะ
7. **โครงเดียว หลาย layout** — ทุกหน้าใช้ title bar → toolbar → panes → status bar แต่การจัดแผงเลือกตามงาน
