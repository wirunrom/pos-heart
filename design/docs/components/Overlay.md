# Overlay
Dialog (ตัดสินใจ/ยืนยัน), Sheet (แก้ไขโดยยังเห็นบริบท) และ Popover (ตัวเลือกเล็ก ๆ ใกล้ปุ่ม) · **Ready**

| | ใช้เมื่อ | ขนาด | ปิดด้วย |
|---|---|---|---|
| **Dialog** | ยืนยันสิ่งที่ย้อนกลับไม่ได้, ใส่ PIN อนุมัติ, คำถามสั้น | กว้าง ≤ 480 | ปุ่ม, `Esc` (= ปุ่มที่ปลอดภัย) · ไม่ปิดเมื่อคลิกนอกถ้ามีข้อมูลที่กรอกไว้ |
| **Sheet** | ตัวเลือกสินค้า/modifier, แก้ไขรายการ, ตัวกรองบนจอแคบ | ด้านข้าง 440 (desktop) / ด้านล่าง ≤ 85% (tablet) | X, `Esc`, คลิก scrim |
| **Popover** | เมนู, combobox, เลือกวันที่ | ตามเนื้อหา | `Esc`, คลิกนอก |

**Dialog anatomy** icon สถานะ (เมื่อเป็น danger) · หัวข้อเป็นคำถาม (“ยกเลิกบิล #A-0192 ทั้งบิล?”) · เนื้อหาบอก**ผลเป็นตัวเลข** · ช่องเหตุผล (ถ้าจำเป็น) · ปุ่ม: ปลอดภัย (ghost) ซ้าย, การกระทำ (danger/primary) ขวา — ใช้คำกริยาเดียวกับหัวข้อ
**Focus** เมื่อเปิด: focus ไปที่ช่องแรกหรือปุ่มที่ปลอดภัย · ขังโฟกัสไว้ใน overlay · เมื่อปิด: คืน focus ไปที่ปุ่มที่เปิด
**ห้าม** ซ้อน Dialog บน Dialog · ห้ามใช้ Dialog กับเรื่องที่ undo ได้ · Sheet ห้ามมีการนำทางไปหน้าอื่นข้างใน
**Motion** เข้า `duration-slow` (Sheet เลื่อน, Dialog fade+scale 0.98) · ออก 0.7× · reduced motion = fade อย่างเดียว
**egui** `egui::Modal` (0.30+) หรือ `Window` + `Area` scrim · Sheet = `Area` ที่ตำแหน่งเคลื่อนด้วย `ctx.animate_value_with_time`
