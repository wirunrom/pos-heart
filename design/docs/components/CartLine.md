# CartLine
หนึ่งบรรทัดในบิล: จำนวน · ชื่อ · ยอด และบรรทัดรองสำหรับตัวเลือก/หมายเหตุ/ราคาต่อหน่วย · **Ready** · *Domain*

**Anatomy** `[qty] ชื่อ ................. ยอด` + `ตัวเลือก (fg-accent) · +ราคาเพิ่ม · × ราคาต่อหน่วย` · ยอดบรรทัด = (ราคา + ตัวเลือก) × จำนวน
**States** default · **current** (`bg-selected`, qty กลับสี — เป็นเป้าหมายของคีย์บอร์ด/การแตะ) · just-added (ไฮไลต์ `duration-base` แล้วจาง) · sent-to-kitchen (Future: แสดง Badge fulfillment, แก้ไขต้องมีเหตุผล)
**Editor (เมื่อ current)** compact: แก้ด้วยคีย์ลัด `+ − F3 F6 Del` · touch: แตะบรรทัดเพื่อเปิดแถบ stepper + ตัวเลือก + ลบ ใต้บรรทัด (ไม่ใช้ swipe-to-delete เป็นทางเดียว)
**Keyboard** `↑↓` เลือกบรรทัด · `+/−` จำนวน · `F3` พิมพ์จำนวน · `F6` หมายเหตุ/ตัวเลือก · `Del` ลบ (Toast เลิกทำ)
**Overflow** ชื่อตัดบรรทัดได้ไม่จำกัด (ในตะกร้าต้องเห็นชื่อเต็ม) · ยอดไม่ตัดและอยู่บรรทัดแรกเสมอ · ตัวเลือกเกิน 3 รายการ ขึ้นบรรทัดใหม่
**A11y** ประกาศเมื่อเพิ่ม/ลบ (“เพิ่มชาไทยเย็น จำนวน 2 รวม 90.00”) · ปุ่มใน editor มี label ครบ
**egui** custom row ใน `ScrollArea` · คืน `CartLineIntent` · ใช้ `scroll_to_me` เมื่อเพิ่มบรรทัด
