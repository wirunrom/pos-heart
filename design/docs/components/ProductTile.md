# ProductTile
การ์ดสินค้าในหน้าขาย แตะหรือคลิกครั้งเดียว = เพิ่ม 1 ชิ้นลงตะกร้า · **Ready** · *Domain*

**Anatomy** ชื่อ (สูงสุด 3 บรรทัด) · มุมขวาบน: Count จำนวนในตะกร้า · ล่างซ้าย: สถานะ/สต็อก/“มีตัวเลือก” · ล่างขวา: ราคา `font-num` 600 (ไม่ตัดเด็ดขาด)

| State | หน้าตา | พฤติกรรม |
|---|---|---|
| default | `bg-raised` + `border-default` | เพิ่ม 1 ชิ้น + ไฮไลต์บรรทัดในตะกร้า |
| in cart | ขอบ 2px `border-selected` + Count | เพิ่มอีก 1 |
| has options | “≡ มีตัวเลือก” | เปิด Sheet ตัวเลือกก่อนเพิ่ม |
| low stock | “เหลือ 3” สี warning | เพิ่มได้ |
| out of stock / not for sale | พื้น sunken + ข้อความ danger | กดไม่ได้ · tooltip บอกเหตุผล · (Future: ผู้จัดการขายเกินได้ด้วย approval) |

**ไม่ใส่รูปภาพในเวอร์ชันแรก** (ร้านส่วนใหญ่ไม่มีรูป และข้อความอ่านเร็วกว่า) — ถ้ามีในอนาคต ให้เพิ่มเป็น variant `with-image` ที่สูงขึ้น ไม่ใช่เปลี่ยนการ์ดเดิม
**Keyboard** การ์ดอยู่ในลำดับ tab ได้แต่ไม่จำเป็น — คนประจำใช้ค้นหา + `Enter` · ลูกศรเลื่อนระหว่างการ์ดเมื่อ focus อยู่ใน grid
**Touch** สูง ≥ 104px กว้างขั้นต่ำ 176 · ตอบสนองทันทีเมื่อแตะ (scale 0.985) · ไม่มี long-press เป็นทางเดียว
**Overflow** ชื่อยาวตัดที่ 3 บรรทัดพร้อมชื่อเต็มใน tooltip/การ์ดรายละเอียด · ราคาไม่ตัด ถ้าที่ไม่พอให้ชื่อหดแทน
**egui** custom: `allocate_exact_size(vec2(w,h), Sense::click())` → painter วาด rect/stroke/text (ใช้ `LayoutJob` ตัดคำเอง) · คืน `TileIntent::{Add, OpenOptions}`
