# StatTile
ตัวเลขสรุป (KPI) และกราฟสำหรับรายงาน · **Experimental**

**StatTile** ป้าย (13 muted) · ค่า `font-num` 22 600 · บรรทัดรอง: การเปลี่ยนแปลง (▲/▼ + % + เทียบกับอะไร) หรือที่มาของตัวเลข (“= ก่อนคืน − คืน”)
**กติกา** แยก ยอดขายก่อนคืน · คืนเงิน · ยอดขายสุทธิ · รายรับ ออกจากกันเสมอ · ค่าลบใช้ `−` + `danger-fg` · ▲/▼ มีข้อความกำกับ ไม่ใช่สีอย่างเดียว · ห้ามย่อ “18.2K” ใน tile (แกนกราฟย่อได้)
**Chart** แท่งสำหรับเทียบช่วงเวลา (วันนี้ = `chart-1` saffron, ช่วงเทียบ = `chart-2` เทาเข้ม) · เส้นสำหรับแนวโน้มหลายวัน · gridlines `chart-grid` · legend อยู่ขวาบน · มีประโยคสรุปใต้กราฟ (“ช่วงขายดีสุด 12:00–13:00”) เพื่อให้คนที่ไม่ดูกราฟก็ได้ข้อมูล
**A11y** กราฟมี `aria-label` + ตารางข้อมูลเดียวกันที่เปิดดูได้ · สีกราฟ ≥ 3:1 กับพื้น และต่างกันที่ความสว่าง
**egui** `egui_plot::BarChart` ได้เร็ว · ถ้าต้องการให้ตรงสเปก (มุมมน, label ไทย) วาดเองด้วย painter
