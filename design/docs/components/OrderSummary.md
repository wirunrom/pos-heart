# OrderSummary
สรุปยอดของบิลและแผงรับเงิน: รวมรายการ → ส่วนลด → **ยอดชำระ** → รับเงิน → **เงินทอน** · **Ready** (จ่ายผสม: Future) · *Domain*

**Anatomy** `ds-summary` (พื้น sunken) ของแถว `ds-kv` (ป้ายซ้าย muted · ค่าขวา `font-num`) · ยอดชำระ `money-xl` · เงินทอน `money-lg` · ตามด้วย chip เงินด่วน และปุ่ม `primary xl`
**กติกาเงิน** ทุกค่าแสดงครบ 2 ตำแหน่ง · ลบใช้ `−` + `danger-fg` · เส้นประคั่นก่อนยอดสำคัญ · ห้ามมีตัวเลขสองตัวที่ใช้ป้ายเดียวกันในหน้าเดียว
**เงินด่วน** “พอดี” + ธนบัตรที่ปัดขึ้นจากยอด (เช่น 1,323.50 → 1,500 / 2,000) · เลือกแล้วเติมช่องรับเงินและคำนวณเงินทอนทันที · Experimental: วัดว่าเร็วขึ้นจริง
**Validation** รับเงินน้อยกว่ายอด → InlineError “รับเงินน้อยกว่ายอดชำระ 323.50” และปุ่มรับเงิน disabled · มากผิดปกติ (> 10× ยอด) → เตือนก่อนยืนยัน
**Keyboard** `F9` focus ช่องรับเงิน (หรือยืนยันเมื่อพร้อม) · `Enter` ยืนยัน · ตัวเลขพิมพ์เข้าช่องรับเงินได้ทันทีเมื่ออยู่ในขั้นรับเงิน
**Pinned** อยู่ท้ายตะกร้าเสมอ ไม่เลื่อนหาย · หลังรับเงินสำเร็จ: แสดงเงินทอนตัวใหญ่จนกว่าจะเริ่มบิลใหม่ + พิมพ์ใบเสร็จ
**Future** จ่ายผสม: รายการวิธีชำระ + “คงเหลือ” · จ่ายบางส่วน: สถานะชำระเป็น “บางส่วน” · ส่วนลด/ภาษี: แถวเพิ่มใน summary โดยไม่เปลี่ยนโครง
**egui** `Grid` 2 คอลัมน์หรือแถว `ui.horizontal` + `with_layout(right_to_left)` · ตัวเลขใช้ `TextStyle::Name("money_xl")`
