# Feedback
Banner (ปัญหาที่ค้างและต้องทำต่อ), Toast (ผลของการกระทำเมื่อครู่ + เลิกทำ) และ InlineError (ปัญหาของช่องเดียว) · **Ready**

| Component | อยู่ที่ | หายไปเมื่อ | มี action |
|---|---|---|---|
| **Banner** | บนสุดของพื้นที่ที่เกี่ยวข้อง | ปัญหาหาย (หรือผู้ใช้ปิด ถ้าไม่สำคัญ) | 0–1 ปุ่ม secondary |
| **Toast** | ล่างกลาง (desktop) / เหนือแถบตะกร้า (tablet) · ชั้น `layer-toast` | 6 วินาที (มี undo) / 4 วินาที · ค้างไว้เมื่อ hover/focus | “เลิกทำ” หรือไม่มี |
| **InlineError** | ใต้ช่องกรอก | แก้ค่าแล้ว | ไม่มี |

**ข้อความ** เกิดอะไรขึ้น + ข้อมูลปลอดภัยไหม + ทำอะไรต่อ (“พิมพ์ใบเสร็จไม่สำเร็จ · ขายสำเร็จแล้ว · พิมพ์ซ้ำ”) · ห้ามโทษผู้ใช้ · รหัสข้อผิดพลาดไว้ใน “รายละเอียด”
**ห้าม** ใช้ Toast กับข้อผิดพลาดที่ต้องแก้ (ใช้ Banner) · ห้ามมี Toast เกิน 3 อันซ้อน (รวมเป็นอันเดียว “ทำแล้ว 4 รายการ”) · ห้ามใช้ modal แจ้งความสำเร็จ
**A11y** Toast = `role=status` (polite) · Banner danger = `role=alert` · ใช้ `Ctrl Z` แทนการกดเลิกทำได้
**egui** Toast stack วาดใน `Area` ที่ตรึงตำแหน่ง (`Order::Foreground`) และเก็บคิวไว้ใน app state พร้อมเวลาหมดอายุ · Banner = `Frame` ธรรมดา
