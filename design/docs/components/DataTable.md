# DataTable
ตารางสำหรับข้อมูลจำนวนมาก พร้อมหัวตารางเรียงได้ เลือกหลายแถว และ BulkBar · **Ready**

**ใช้เมื่อ** ต้องเทียบหลายคุณสมบัติของหลายรายการ (สินค้า, บิล, รายงาน) · **ไม่ควรใช้** บนหน้าขาย หรือเมื่อมีแค่ 1–2 คุณสมบัติ (ใช้ List)
**Anatomy** หัวตารางตรึงไว้ (12px 600 muted) · แถว `row-height` · คอลัมน์แรก checkbox · คอลัมน์ตัวเลขชิดขวาด้วย `font-num` · tfoot สำหรับยอดรวม
**Rows** hover `bg-hover` · selected `bg-selected` · ชื่อยาวตัดบรรทัดได้ (`is-wrap`) พร้อมบรรทัดรองสำหรับรหัส · ค่าว่างใช้ “—” · สถานะใช้ Badge
**BulkBar** แทนที่แถวเครื่องมือเมื่อเลือก ≥ 1 แถว · บอกจำนวน + action + ล้างการเลือก · พื้น `bg-inverse`
**Keyboard** `↑↓` ย้ายแถว · `Space` เลือก · `Shift+คลิก/↑↓` เลือกเป็นช่วง · `Ctrl A` เลือกทั้งหมดในผลกรอง · `Enter` เปิดรายละเอียด
**Touch** แถว 56px · แตะแถว = เปิด, แตะ checkbox = เลือก · บนจอ < 900 แปลงเป็นรายการ 2 บรรทัด
**Responsive** ซ่อนคอลัมน์ตามลำดับความสำคัญที่กำหนดไว้ใน view-model · **ห้ามซ่อนคอลัมน์เงินหลัก**
**egui** `egui_extras::TableBuilder` (sticky header, `Column::auto/remainder`) · checkbox/badge เป็น widget ของเรา · ข้อมูล > 1,000 แถวใช้ `body.rows()` (virtualized)
