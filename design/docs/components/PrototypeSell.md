# PrototypeSell
Interactive prototype ของหน้าขาย ใช้ทดลองกับ tokens, components และ patterns จริงของระบบ (design reference ไม่ใช่โค้ดแอป)

**ลองได้:** แตะ/คลิกการ์ดสินค้า · พิมพ์ค้นหาแล้วกด `Enter` · เลือกบรรทัดด้วย `↑↓` แล้วกด `+ −` / `Del` · ลบแล้ว `Ctrl Z` หรือกด “เลิกทำ” · สินค้าที่มีตัวเลือก (ชาไทย, กาแฟ) เปิด Sheet ให้เลือก · `F4` พักบิล แล้วเปิดคืนจากแท็บ “พักไว้” · `F9` ไปที่ช่องรับเงิน / ปุ่มเงินด่วน / `Enter` เพื่อรับเงิน · รับเงินไม่พอจะขึ้น error · เงินสูงเกิน 10 เท่าต้องยืนยันอีกครั้ง · สต็อกลดลงหลังขาย
**สลับได้:** Light/Dark · ไทย/English · Compact/Touch · 1000×700 / 1280×820
ข้อมูลทั้งหมดเป็นข้อมูลตัวอย่าง และรีเซ็ตเมื่อโหลดหน้าใหม่
