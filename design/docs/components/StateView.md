# StateView
สถานะของพื้นที่เนื้อหาทั้งก้อน: ว่าง (ครั้งแรก / ไม่พบผล), กำลังโหลด, ผิดพลาด และออฟไลน์ · **Ready**

| State | หัวข้อ | เนื้อหา | Action |
|---|---|---|---|
| **First use** | “ยังไม่มีสินค้า” | ประโยชน์ที่จะได้ 1 ประโยค | ปุ่ม primary สร้างอันแรก |
| **No results** | “ไม่พบ ‘ชาเขียว’” | บอกตัวกรองที่เปิดอยู่ | ล้างตัวกรอง / เพิ่ม ‘…’ |
| **Loading** | — | Skeleton ตามรูปร่างจริง (แสดงหลัง 300ms เท่านั้น) | — |
| **Error** | “โหลดรายงานไม่สำเร็จ” | ข้อมูลยังปลอดภัยไหม | ลองอีกครั้ง |
| **Offline** | “ออฟไลน์ — ขายต่อได้” | สิ่งที่ทำได้/ไม่ได้ + จำนวนรายการที่รอ sync | — |

**กติกา** StateView อยู่*ในพื้นที่*ที่ว่าง ไม่ใช่ทั้งหน้า (แถบบนและตะกร้ายังใช้ได้) · ข้อความสั้น ไม่มีภาพประกอบตกแต่ง (ใช้ icon ในกล่อง sunken)
**Reduced motion** skeleton หยุดกระพริบ
**egui** layout แนวตั้งกึ่งกลาง (`vertical_centered`) · skeleton = `rect_filled` + สีจาก `animate_value` (หรือคงที่เมื่อ reduced motion)
