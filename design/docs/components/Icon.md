# Icon
ชุด icon แบบเส้น grid 24 เส้นหนา 1.8 ปลายมน ขนาด 16/20/24 · **Ready**

**ใช้** ประกอบข้อความในปุ่ม เมนู และสถานะ · IconButton สำหรับการกระทำรองที่เข้าใจกันทั่วไปเท่านั้น (ปิด, เพิ่มเติม, พัก, หมายเหตุ) และต้องมี label/tooltip
**สี** ใช้ `currentColor` (ตามข้อความ) · icon สถานะใช้ `{status}-fg`
**ที่มา** แนะนำ Lucide (ISC) เป็นฐาน — ชุดในการ์ดเป็นตัวอย่างรูปทรงที่ต้องการ · เพิ่ม icon ใหม่ต้องวาดบน grid เดียวกัน
**egui** แปลง SVG เป็น texture ตอน build (`resvg`) หรือใช้ `egui_extras` image loader · หรือใช้ icon font (เช่น Lucide font) แล้วเพิ่มเป็น `FontFamily::Name("icons")` — ทางนี้ใช้สีและขนาดได้เหมือนข้อความ
