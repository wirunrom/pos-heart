# POS Heart — ภาพหน้าจอ (Design System v0.2)

เปิด `index.html` เพื่อดูภาพรวม เลือกรูปทรง (โค้ง / เหลี่ยม) ค้นหาชื่อหน้า และคลิกภาพเปิดขนาดเต็ม

- ทุกหน้าจอ/สถานะถ่ายสองแบบ: `soft/` (โค้ง ลอยเป็นการ์ด) และ `square/` (เหลี่ยม ชิดขอบ) ชื่อไฟล์ตรงกันเพื่อเทียบภาพ
- ภาษาไทย · Compact · สีหลักหญ้าฝรั่น (saffron) · viewport 1280×820 · native macOS debug build
- ไม่มีโหมดสว่าง/มืดแล้ว (v0.2 มีธีมเดียว) ภาพชุดเก่า `light/` `dark/` ของ v0.1 ถูกลบออก
- ทุกภาพใช้ข้อมูลสมมติ ฐานข้อมูลและไฟล์ตั้งค่าที่ใช้แคปอยู่ในโฟลเดอร์ชั่วคราวนอกโปรเจกต์
- เป็นภาพ layout จาก debug presets ไม่ได้แสดงข้อมูลร้านจริง และไม่ได้ยืนยันว่ากดทำธุรกรรมทุกภาพ
- หน้าที่เนื้อหายาวเป็นภาพ viewport; ภาษี เครื่องพิมพ์ บทบาท สำรองอัตโนมัติ และคลาวด์มีภาพส่วนล่างแยกให้
- รูปสินค้าลายสีเป็นรูปตัวอย่างที่ seed สร้าง ไม่ใช่รูปสินค้าจริง
- ข้อผิดพลาด CSV/เครื่องพิมพ์ สถานะกู้คืน และสถานะคลาวด์ (`settings-cloud`) เป็นตัวอย่างจาก debug preset ไม่ได้เชื่อมต่อเครื่องพิมพ์หรือคลาวด์จริง; ภาพจับคู่เครื่องเปิด hub เฉพาะ loopback ชั่วคราว

## หมวดภาพ

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `01-main` | หน้าหลัก ขาย สินค้า ประวัติ กะ รายงาน ตั้งค่า กิจกรรม เริ่มต้นร้าน ล็อก เปิดกะ |
| `02-sell` | บิลพัก ตัวเลือก ส่วนลด QR แบ่งจ่าย แยกบิล คูปอง โต๊ะ จอครัว |
| `03-catalog` | สินค้า ต้นทุน สูตร สต็อก CSV หมวด ชุดตัวเลือก วัตถุดิบ |
| `04-purchasing` | ผู้ขาย ใบสั่งซื้อ รับของ ประวัติ และยกเลิกยอดค้าง |
| `05-history` | รายละเอียดบิล คืนสินค้า ยกเลิก ใบกำกับ ใบลดหนี้ และตัวอย่างพิมพ์ |
| `06-shifts` | นับและปิดกะ ยืนยัน ประวัติกะ |
| `07-reports` | สัปดาห์ เดือน หมวด พนักงาน โปรโมชัน วัตถุดิบ กำไร แยกเครื่องขาย |
| `08-settings` | ทุกหมวดตั้งค่า (รวมอุปกรณ์และคลาวด์) และหน้าต่างแก้ไขที่เกี่ยวข้อง |
| `09-dialogs` | ค้นหา ปรับหน้าจอ ขออนุมัติ ตรวจสำรองและกู้คืน กู้คืนจากไฟล์คลาวด์ |

`manifest.json` ระบุ page, preset, รูปทรง และไฟล์ของทุกภาพ

## สร้างภาพใหม่

ต้องปลดล็อกหน้าจอ macOS และมี Rust/dependencies ของโปรเจกต์พร้อมแล้ว รันจากรากโปรเจกต์:

```sh
CARGO_INCREMENTAL=0 cargo build -p pos-desktop --bin pos-heart --example seed_screens
python3 screenshots/2026-10-14/capture.py
```

สคริปต์สร้างข้อมูลตัวอย่างแยกใน temp ด้วย `seed_screens` (รวม `--registers` สำหรับรายงานแยกเครื่องขาย) และคัดลอก **fixture ที่ปิดฐานข้อมูลแล้ว** เป็นชุดใหม่ให้แต่ละภาพ เพื่อไม่ให้ preview หนึ่งกระทบภาพถัดไป ไม่แตะฐานข้อมูลร้านหรือแอปที่เปิดใช้งานอยู่

หากหยุดกลางทาง ใช้ `--resume` เพื่อเก็บ PNG ที่เสร็จแล้วและแคปเฉพาะภาพที่ยังไม่มี สคริปต์ไม่กด Print ไม่ส่งข้อมูลผู้ขาย ไม่เชื่อมต่อเครื่องพิมพ์หรือคลาวด์
