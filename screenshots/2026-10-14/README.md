# POS Heart — ภาพหน้าจอ Light / Dark

เปิด `index.html` เพื่อดูภาพรวม เลือกธีม ค้นหาชื่อหน้า และคลิกภาพเปิดขนาดเต็ม

- 96 หน้าจอ/สถานะต่อธีม รวม 192 ภาพ PNG
- ภาษาไทย · Compact · viewport 1280×820 · native macOS debug build
- `light/` และ `dark/` ใช้โครงสร้างและชื่อไฟล์ตรงกันเพื่อเทียบภาพ
- ทุกภาพใช้ข้อมูลสมมติ ฐานข้อมูลและไฟล์ตั้งค่าที่ใช้แคปอยู่ในโฟลเดอร์ชั่วคราวนอกโปรเจกต์
- เป็นภาพ layout จาก debug presets ไม่ได้แสดงข้อมูลร้านจริง และไม่ได้ยืนยันว่ากดทำธุรกรรมทุกภาพ
- หน้าที่เนื้อหายาวเป็นภาพ viewport; ภาษี เครื่องพิมพ์ บทบาท และสำรองอัตโนมัติมีภาพส่วนล่างแยกให้
- รูปสินค้าลายสีเป็นรูปตัวอย่างที่ seed สร้าง ไม่ใช่รูปสินค้าจริง
- ข้อผิดพลาด CSV/เครื่องพิมพ์และสถานะกู้คืนบางภาพเป็น debug preset ตัวอย่าง ไม่ใช่ข้อผิดพลาดจากข้อมูลร้านหรืออุปกรณ์จริง

## หมวดภาพ

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `01-main` | หน้าหลัก ขาย สินค้า ประวัติ กะ รายงาน ตั้งค่า กิจกรรม เริ่มต้นร้าน ล็อก เปิดกะ |
| `02-sell` | บิลพัก ตัวเลือก ส่วนลด QR แบ่งจ่าย แยกบิล คูปอง โต๊ะ จอครัว |
| `03-catalog` | สินค้า ต้นทุน สูตร สต็อก CSV หมวด ชุดตัวเลือก วัตถุดิบ |
| `04-purchasing` | ผู้ขาย ใบสั่งซื้อ รับของ ประวัติ และยกเลิกยอดค้าง |
| `05-history` | รายละเอียดบิล คืนสินค้า ยกเลิก ใบกำกับ ใบลดหนี้ และตัวอย่างพิมพ์ |
| `06-shifts` | นับและปิดกะ ยืนยัน ประวัติกะ |
| `07-reports` | สัปดาห์ เดือน หมวด พนักงาน โปรโมชัน วัตถุดิบ กำไร |
| `08-settings` | ทั้ง 8 หมวดตั้งค่า และหน้าต่างแก้ไขที่เกี่ยวข้อง |
| `09-dialogs` | ค้นหา ปรับหน้าจอ ขออนุมัติ ตรวจสำรองและกู้คืน |

`manifest.json` ระบุ page, preset, theme และไฟล์ของทุกภาพ

## สร้างภาพใหม่

ต้องปลดล็อกหน้าจอ macOS และมี Rust/dependencies ของโปรเจกต์พร้อมแล้ว รันจากรากโปรเจกต์:

```sh
CARGO_INCREMENTAL=0 cargo build -p pos-desktop --offline
python3 screenshots/2026-10-14/capture.py
```

สคริปต์สร้างข้อมูลตัวอย่างแยกใน temp โดยเลือก `seed_screens` อย่างชัดเจน และคัดลอก **fixture ที่ปิดฐานข้อมูลแล้ว** เป็นชุดใหม่ให้แต่ละภาพ เพื่อไม่ให้ preview หนึ่งกระทบภาพถัดไป ไม่แตะฐานข้อมูลร้านหรือแอปที่เปิดใช้งานอยู่

หากหยุดกลางทาง ใช้ `--resume` เพื่อเก็บ PNG ที่เสร็จแล้วและแคปเฉพาะภาพที่ยังไม่มี สคริปต์ไม่กด Print ไม่ส่งข้อมูลผู้ขาย และไม่เชื่อมต่อเครื่องพิมพ์
